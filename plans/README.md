## Recommended execution order

1. **001** and **002** are independent (different files) — can run in either order or in parallel.
2. **003** is independent of 001/002 (touches only `app/globals.css`'s reduced-motion block) but should run **before 004**, since plan 004's steps branch on whether 003's reduced-motion block already exists — running 003 first avoids the conditional-merge step in 004.
3. **004** last, since it depends on 003's reduced-motion block state (see above) and adds to `app/globals.css` in the same region.

## Dependencies

- 004 reads/extends the same `@media (prefers-reduced-motion: reduce)` block in `app/globals.css` that 003 modifies. If 003 hasn't been applied when 004 runs, 004's steps fall back to using the original (pre-003) block — see plan 004's Boundaries section.
- 001 and 002 have no dependencies on each other or on 003/004.
